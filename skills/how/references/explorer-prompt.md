# 探索提示

仅在确有独立调查范围、使用当前宿主委派工具时采用。填入实际问题、目标路径与分工，不需要保留占位符；默认继承模型。任务只读，不编辑文件或外部状态。

向探索者提供：

- 用户原问题及本次范围。
- 已定位的入口、关键符号和可复用线索。
- 其负责的调用链、数据边界或状态生命周期，说明与其他调查的分界。

要求返回：

- 找到的核心组件：名称、职责、核对过的文件与行号。
- 触发到结果的执行和数据流，包括分支、错误、异步及清理。
- 与其他模块的输入输出、依赖和职责边界。
- 影响理解的配置、测试和非直观行为。
- 未能追踪的部分及其原因。

用已读取的实现支持结论，明确事实与推断。不要把函数名、代码风格或文档中的愿望当成运行事实，也不要为填满格式列出无关文件。
