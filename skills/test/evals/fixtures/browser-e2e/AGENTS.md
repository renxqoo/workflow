# Browser E2E fixture

这是一个小型模型目录站点。测试与实现以本文件中的业务规则为准，现有测试可能有错。

- 目录只展示已发布的模型。内容服务故障时显示故障提示，分类只保留“All”；服务恢复后恢复分类和模型卡片。用户可按分类筛选，并通过卡片打开详情。
- 窄屏菜单打开后，键盘焦点必须进入菜单；关闭后焦点回到打开按钮。用户可以从菜单进入目录。
- `/home-v2` 的特殊重定向规则已退役。没有约定该 URL 的最终状态码或新跳转目标。
- 没有“1440px 必须显示三列”的产品规则。视口尺寸可用于进入窄屏交互，但固定列数不是本次浏览器功能回归目标。

先运行 `git status --short`。依赖安装后使用 `npm run test:e2e` 验证；如果缺少 Chromium，可使用 `npx playwright install chromium`。可以修复菜单焦点缺陷；不得通过更改业务规则或测试数据让错误断言变绿，不改 CI，不提交或推送。
