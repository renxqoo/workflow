# 支付通道材料

- 发起支付支持 merchant_attempt_key，相同商户下同一个 key 表示同一次支付尝试；响应可能在通道已经处理后因网络超时丢失。
- 可以按 merchant_attempt_key 查询支付状态。通道不参与本地数据库事务。
- 回调需要通过现有适配器验签。回调可能重复和乱序；provider_event_id 在商户范围内标识一次事件。同一笔支付的状态也可能由多个不同事件通知。
- 本地订单 ID、客户端 request_key、通道尝试 key、通道支付 ID 与事件 ID 是不同标识。
- 通道退款接口存在，但当前材料没有确认其幂等或查询保证，也没有退款失败的运维处置协议。
- 没有承诺客户端超时或本地取消会撤销已经发出的支付请求。
