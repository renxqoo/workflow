# 定位纪律：三档判据、回路手段、假设排序、反过度闸

定位加工是本 skill 的灵魂——issue 的价值上限不在模板，在把「现象」
加工成「已定位的问题陈述」。但定位有边界：目标是**给下游起点，
不是替下游干活**——定位到「下游不必重新发现问题的存在」即停。

## 三档判据（档位由证据决定，不由感觉决定）

| 档 | 名称 | 判据（差一点都不算） | 产出物 |
| --- | --- | --- | --- |
| 2 | 复现定位 | **跑过复现命令且亲眼见过红**（断言用户描述的确切症状，不是「没报错就算过」） | 复现命令 + 红/绿输出 + 最小化说明 |
| 1 | 静态定位 | 读了代码/日志，能指出疑似位置（行为级）| **≥3 个排序假设**，每条带证伪条件 |
| 0 | 纯现象 | 只有描述，没有定位 | 已尝试手段清单 + 各自失败原因，含「缺什么才能到下一档」 |

- 档位是**证据性质**不是自信程度：「我很确定是这里」没有复现就是档 1；
- 难度与档位无关——一条命令见红的小问题也是档 2，「金标准」指证据
  确定性不指获得难度；
- 虚标档 2 比档 0 更糟——下游会信任复现命令，跑不红时怀疑自己而不是
  issue。宁可如实标档 1。

## 到档 2 的回路手段（按成本从低到高试）

1. **失败测试**：在能触达 bug 的接缝写断言确切症状的测试；
2. **HTTP 脚本**：curl / fetch 打运行中的 dev server；
3. **CLI 调用**：fixture 输入跑命令，diff 输出对照已知正确值；
4. **headless 浏览器脚本**：驱动 UI 断言 DOM/console/network；
5. **重放捕获**：真实请求/事件落盘后离线重放；
6. **丢弃式 harness**：最小子系统 + mock 依赖单函数调用触发；
7. **属性/模糊循环**：「有时错」类 bug 跑千次随机输入找失败模式；
8. **二分**：两状态间自动切换验证（配合版本管理 bisect）；
9. **差分**：同一输入过旧/新版本，diff 输出；
10. **运行时观测回路**（长时程/资源类）：丢弃式 harness 循环打真实
    子系统 + 采样可断言度量（内存增速斜率 / 句柄数 / 队列深度），
    阈值断言替代错误输出。

回路质量四问（有了回路再问）：能更快吗？信号能更尖吗（断言确切症状
而非「没崩」）？能更确定吗（固定时间/种子/隔离环境）？agent 能独立
跑吗？——30 秒确定红的能力才是好回路（长时程类见下，窗口拉长不算
差回路）。

**确定性差的 bug**（竞态/偶发）：目标不是干净复现而是**提高复现率**
——循环触发百次、加压、收窄时序窗口。50% 复现的 bug 可调试，1% 不可。

**长时程/资源类问题**（慢泄漏/句柄泄漏/渐增衰减）：「红」不是错误
输出，是**度量阈值**——先把症状量化为可断言度量（指标 + 阈值 +
观察窗口，如「heapUsed 每万次请求增长 > X」），再按回路 10 构造。
观察窗口拉长（小时/天级）不算降档，判据仍是「跑过且见过红」；
需要基线曲线或真实流量时程才能构造的，按「环境不可得」降档。

## 档 1 的假设排序（硬门槛）

静态定位**禁止单假设**——单假设就是锚定。格式：

```
排序假设（按可能性降序）：
1. 若是 <X 模块的 Y 行为> 出错，则 <改 Z> 应使现象消失
2. 若是 <…>，则 <…>
3. 若是 <…>，则 <…>
```

每条的证伪条件必须可执行——写不出预测的假设是直觉，丢弃或锐化。
静态扫描零命中时不要硬凑纸面假设——零命中本身就是有效发现，降档 0
并在已尝试清单里写明扫过什么、命中为什么趋零。

备择假设优先覆盖「审查误报的典型来源」（上层已有兑底/有意为之的
不可观测路径/环境差异）——入口 c 的 finding 尤甚。

## 反过度定位闸（何时停）

- **档 2 达成即停**——继续诊断是在替下游做 diagnosing，越界；
- **一条回路尝试失败 + 假设排序完成 → 接受档 1**。假设排序本身给
  下游 80% 的起点，不必追求复现；
- **环境不可得**（要生产数据/特定硬件/内部系统权限/**需长时程运行
  观测的基线或流量时程**）→ 立即降档，写明「缺什么才能到下一档」
  ——这句话本身就是给下游/用户的行动项；
- 判断标准一句话：**下游拿到这个 issue，还需要重新发现「问题的存在」
  吗？** 不需要 → 定位够了。需要 → 再挖一层。

## 输入档位映射（入口 c 审查残留）

pr-review-loop 的 finding 证据级可映射到三档：其「跑了/应用里复现」
（≥第 4 级）且有红输出 → 档 2；「指到行/走了路径」（2-3 级）→ 档 1
（补假设排序）；纸面 finding → 档 0/1 按其内容。台账与证据原样保留，
档位产出物按映射补齐。

**台账无证据级列时**（上游台账格式旧或被截）：按 finding 原文的证据
动词反推（「跑了/实测/复现」→4 级；「file:line/指到」→2-3 级；
纯断言→纸面），并在 issue 元数据注明「证据级由动词反推」——反推
有损失，注明才诚实。
